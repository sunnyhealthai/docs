The Sunny Agents SDK is a TypeScript/JavaScript library for browser environments. It provides full type definitions and is designed to work seamlessly with modern JavaScript frameworks.

## Installation

Install the SDK using your preferred package manager:

<CodeBlocks>
```bash npm
npm install @sunnyhealthai/agents-sdk
```

```bash pnpm
pnpm add @sunnyhealthai/agents-sdk
```

```bash yarn
yarn add @sunnyhealthai/agents-sdk
```
</CodeBlocks>

## Package Information

- **Package Name**: `@sunnyhealthai/agents-sdk`
- **Current Version**: `0.0.16`
- **Registry**: [npm](https://www.npmjs.com/package/@sunnyhealthai/agents-sdk)
- **TypeScript**: Full type definitions included
- **Module Format**: ES modules (ESM)
- **Runtime**: Browser (uses DOM APIs)

## Versioning

We follow [semantic versioning](https://semver.org/) (semver) principles:

- **Major versions**: Breaking changes
- **Minor versions**: New features (backward compatible)
- **Patch versions**: Bug fixes (backward compatible)

We won't make breaking changes in minor or patch releases.

## TypeScript Support

The SDK is written in TypeScript and includes comprehensive type definitions. Import types as needed:

```typescript
import {
  // Core APIs
  SunnyAgentsClient,
  attachSunnyChat,
  createSunnyChat, // Unified entry point (recommended)

  // Types
  type ConversationState,
  type SunnyAgentMessage,
  type SunnyAgentsConfig,
  type SendMessageOptions,
  type SunnyAgentsClientSnapshot,
  type UnifiedSunnyChatOptions,
  type SdkAuthType,
  type SdkAuthConfig,
  type VanillaChatOptions,
  type VanillaChatInstance,
  type VanillaChatColors,

  // Artifact types
  type ChatArtifact,
  type DoctorProfileArtifact,
  type ProviderSearchResultsArtifact,
  type ProviderResult,
  type LocationResult,
} from "@sunnyhealthai/agents-sdk";
```

## Framework Compatibility

The SDK is framework-agnostic and works with:

- **React** - Use hooks to integrate with React components
- **Vue** - Use with Vue's reactivity system
- **Angular** - Use with Angular services
- **Svelte** - Use with Svelte stores
- **Vanilla JavaScript** - Use directly without any framework

## Usage

### Unified Entry Point (Recommended)

The `createSunnyChat` function provides the simplest way to set up chat with automatic authentication handling. You provide three required parameters and the server handles all auth configuration:

```typescript
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "saml", // or "oidc", "passwordless", "tokenExchange"
});
// Use chat.client for programmatic access; call chat.destroy() to clean up
// Switch auth type at runtime: chat.setAuthType("oidc")
```

### Headless Client

For custom UI implementations:

```typescript
import { SunnyAgentsClient } from "@sunnyhealthai/agents-sdk";

// websocketUrl defaults to wss://chat.api.sunnyhealthai-staging.com
const client = new SunnyAgentsClient();
```

### Vanilla Widget

For quick integration with a pre-built UI and manual configuration:

```typescript
import { attachSunnyChat } from "@sunnyhealthai/agents-sdk";

const { client, destroy } = attachSunnyChat({
  container: document.getElementById("chat"),
  config: {
    websocketUrl: "wss://chat.api.sunnyhealthai-staging.com",
  },
});
```
