The Sunny Agents SDK is a TypeScript/JavaScript library that works in both browser and Node.js environments. It provides full type definitions and is designed to work seamlessly with modern JavaScript frameworks.

## Installation

Install the SDK using your preferred package manager:

<CodeBlocks>
```bash npm
npm install @sunnyhealthai/agents-sdk
```

```bash pnpm
pnpm add @sunnyhealthai/agents-sdk
```

```bash yarn
yarn add @sunnyhealthai/agents-sdk
```
</CodeBlocks>

## Package Information

- **Package Name**: `@sunnyhealthai/agents-sdk`
- **Current Version**: `0.0.11`
- **Registry**: [npm](https://www.npmjs.com/package/@sunnyhealthai/agents-sdk)
- **TypeScript**: Full type definitions included
- **ESM & CJS**: Supports both ES modules and CommonJS
- **Browser & Node**: Works in both environments

- **Major versions**: Breaking changes
- **Minor versions**: New features (backward compatible)


## Usage

### Unified Entry Point (Recommended)

The `createSunnyChat` function provides the simplest way to set up chat with automatic authentication handling:

```typescript
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

// SAML/OIDC authentication (auto-login)
const { client, destroy } = await createSunnyChat({
  container: document.getElementById("chat"),
  auth: {
    type: "saml",
    domain: "your-tenant.auth0.com",
    clientId: "your-client-id",
    connection: "guardian-saml", // Auto-login enabled
    audience: "https://api.sunnyhealthai-staging.com",
  },
});
// Use client for programmatic access; call destroy() to clean up
```

### Headless Client

For custom UI implementations:

```typescript
import { SunnyAgentsClient } from "@sunnyhealthai/agents-sdk";

const client = new SunnyAgentsClient({
  websocketUrl: "wss://chat.api.sunnyhealthai-staging.com",
});
```

### Vanilla Widget

For quick integration with a pre-built UI:

```typescript
import { attachSunnyChat } from "@sunnyhealthai/agents-sdk";

attachSunnyChat({
  container: document.getElementById("chat"),
  config: {
    websocketUrl: "wss://chat.api.sunnyhealthai-staging.com",
  },
});
```
