This tutorial walks you through setting up authentication for the Sunny Agents SDK, including integration with Auth0, Firebase, and custom authentication providers.

## Overview

The SDK supports multiple authentication methods:

1. **SAML/OIDC Authentication** - Enterprise SSO via Auth0 (recommended for enterprise apps)
2. **Custom Token Exchange** - OAuth 2.0 token exchange for custom auth providers
3. **Passwordless Authentication** - Email or SMS-based authentication without passwords
4. **Anonymous Mode** - Local-only conversations without authentication

This tutorial covers all authentication methods and helps you choose the right one for your use case.

## Quick start: SAML/OIDC Authentication (Recommended)

The easiest way to add authentication is using the unified `createSunnyChat` API with SAML/OIDC. All Auth0 configuration (domain, client ID, connection) is provided by the server automatically:

### Step 1: Configure SAML/OIDC

```typescript
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "saml", // or "oidc"
});
```

### Step 2: Test authentication

Authentication happens automatically when you create the chat instance. The SDK will:
1. Connect to the WebSocket and receive auth config from the server
2. Trigger SAML/OIDC login (popup)
3. Send `auth.upgrade` message with ID token
4. Receive `auth.upgraded` response to complete authentication

## Custom Token Exchange Setup

For applications with custom authentication providers:

### Step 1: Configure token exchange

```typescript
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "tokenExchange",
  idTokenProvider: async () => {
    // Return ID token from your auth provider
    return localStorage.getItem("id_token");
  },
});
```

**Or use the headless client directly:**

```typescript
import { SunnyAgentsClient } from "@sunnyhealthai/agents-sdk";

const client = new SunnyAgentsClient({
  idTokenProvider: async () => {
    // Return ID token from your auth provider
    return localStorage.getItem("id_token");
  },
  tokenExchange: {
    partnerName: "your-partner-name",
    audience: "https://api.sunnyhealthai-staging.com",
    clientId: "your-client-id",
    organization: "org_xxx",
  },
});
```

### Step 2: Test authentication

```typescript
// Send a message - authentication happens automatically
await client.sendMessage("Hello!");
```

## Passwordless Authentication Setup

Passwordless authentication is the simplest flow. Users verify via email or SMS OTP, and the SDK handles the verification UI in-chat:

```typescript
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "passwordless",
});

// The chat starts in anonymous mode. When the user is prompted to verify,
// a verification form appears in the chat automatically.
```

## Auth0 integration

### Install Auth0 SDK

```bash
npm install @auth0/auth0-react
```

### React component

```tsx
import { useAuth0 } from "@auth0/auth0-react";
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";
import { useEffect, useRef } from "react";
import type { VanillaChatInstance } from "@sunnyhealthai/agents-sdk";

export function AuthenticatedChat() {
  const { getIdTokenClaims, isAuthenticated } = useAuth0();
  const containerRef = useRef<HTMLDivElement>(null);
  const chatRef = useRef<VanillaChatInstance | null>(null);

  useEffect(() => {
    if (!isAuthenticated || !containerRef.current) return;

    const initChat = async () => {
      chatRef.current = await createSunnyChat({
        container: containerRef.current!,
        partnerIdentifier: "acme-health",
        publicKey: "pk-sunnyagents_abc_xyz",
        authType: "tokenExchange",
        idTokenProvider: async () => {
          const claims = await getIdTokenClaims();
          return claims?.__raw || null;
        },
      });
    };

    initChat();

    return () => {
      chatRef.current?.destroy();
    };
  }, [isAuthenticated, getIdTokenClaims]);

  if (!isAuthenticated) {
    return <div>Please log in to use chat</div>;
  }

  return <div ref={containerRef} />;
}
```

### Vanilla JavaScript with Auth0

```javascript
import { createAuth0Client } from "@auth0/auth0-spa-js";
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

const auth0 = await createAuth0Client({
  domain: "your-domain.auth0.com",
  clientId: "your-client-id",
});

// Check if authenticated
const isAuthenticated = await auth0.isAuthenticated();

if (!isAuthenticated) {
  await auth0.loginWithRedirect();
}

// Create Sunny Chat with Auth0 token exchange
const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "tokenExchange",
  idTokenProvider: async () => {
    const claims = await auth0.getIdTokenClaims();
    return claims?.__raw || null;
  },
});
```

## Firebase integration

### Install Firebase SDK

```bash
npm install firebase
```

### React component

```tsx
import { getAuth } from "firebase/auth";
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";
import { useEffect, useRef } from "react";
import { useAuthState } from "react-firebase-hooks/auth";
import type { VanillaChatInstance } from "@sunnyhealthai/agents-sdk";

const auth = getAuth();

export function FirebaseChat() {
  const [user, loading] = useAuthState(auth);
  const containerRef = useRef<HTMLDivElement>(null);
  const chatRef = useRef<VanillaChatInstance | null>(null);

  useEffect(() => {
    if (!user || loading || !containerRef.current) return;

    const initChat = async () => {
      chatRef.current = await createSunnyChat({
        container: containerRef.current!,
        partnerIdentifier: "acme-health",
        publicKey: "pk-sunnyagents_abc_xyz",
        authType: "tokenExchange",
        idTokenProvider: async () => {
          if (!user) return null;
          return await user.getIdToken();
        },
      });
    };

    initChat();

    return () => {
      chatRef.current?.destroy();
    };
  }, [user, loading]);

  if (loading) {
    return <div>Loading...</div>;
  }

  if (!user) {
    return <div>Please log in</div>;
  }

  return <div ref={containerRef} />;
}
```

## Custom authentication provider

### Example with custom token endpoint

```typescript
import { createSunnyChat } from "@sunnyhealthai/agents-sdk";

const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "tokenExchange",
  idTokenProvider: async () => {
    try {
      // Call your custom auth endpoint
      const response = await fetch("/api/auth/token", {
        credentials: "include", // Include cookies
      });

      if (!response.ok) {
        return null;
      }

      const data = await response.json();
      return data.idToken;
    } catch (error) {
      console.error("Failed to get ID token:", error);
      return null;
    }
  },
});
```

**Or use the headless client for custom UIs:**

```typescript
import { SunnyAgentsClient } from "@sunnyhealthai/agents-sdk";

async function getIdToken(): Promise<string | null> {
  try {
    const response = await fetch("/api/auth/token", {
      credentials: "include",
    });
    if (!response.ok) return null;
    const data = await response.json();
    return data.idToken;
  } catch (error) {
    console.error("Failed to get ID token:", error);
    return null;
  }
}

const client = new SunnyAgentsClient({
  idTokenProvider: getIdToken,
  tokenExchange: {
    partnerName: "your-partner-name",
    audience: "https://api.sunnyhealthai-staging.com",
    clientId: "your-client-id",
    organization: "org_xxx",
  },
});
```

## Switching auth type at runtime

The `createSunnyChat` API supports switching auth types at runtime using `setAuthType`:

```typescript
const chat = await createSunnyChat({
  container: document.getElementById("chat"),
  partnerIdentifier: "acme-health",
  publicKey: "pk-sunnyagents_abc_xyz",
  authType: "passwordless",
});

// Switch to SAML authentication
await chat.setAuthType("saml");

// Switch to token exchange with a new provider
await chat.setAuthType("tokenExchange", {
  idTokenProvider: async () => getMyToken(),
});
```

## Handling token refresh

The SDK automatically refreshes tokens when they expire. However, you may need to handle refresh in your ID token provider:

### Auth0 example

```typescript
idTokenProvider: async () => {
  const claims = await getIdTokenClaims({
    cache: false, // Force refresh
  });
  return claims?.__raw || null;
}
```

### Firebase example

```typescript
idTokenProvider: async () => {
  if (!user) return null;
  // Firebase automatically refreshes tokens
  return await user.getIdToken(true); // Force refresh
}
```

## Error handling

### Handle authentication errors

```typescript
try {
  await client.sendMessage("Hello!");
} catch (error) {
  if (error.message.includes("token") || error.message.includes("auth")) {
    // Token expired or invalid
    console.error("Authentication error:", error);
    
    // Redirect to login or refresh token
    window.location.href = "/login";
  } else {
    // Other errors
    console.error("Error:", error);
  }
}
```

### Check authentication status

```typescript
// Listen for state changes
client.on("snapshot", (snapshot) => {
  // Check if we have an active conversation
  // If not, authentication may have failed
});
```

## Best practices

1. **Secure storage**: Don't store ID tokens in localStorage for sensitive apps
2. **Token refresh**: Let the SDK handle token refresh automatically
3. **Error handling**: Always handle authentication errors
4. **Loading states**: Show loading indicators during authentication
5. **Session management**: Use custom session keys for multi-tenant apps
